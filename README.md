AI-powered Criminal Detection & Smart CCTV Tracking System for Police Assistance.

An AI-powered intelligent CCTV surveillance system for crime detection, suspect identification, and automated law enforcement assistance using computer vision and machine learning.

---

## 📌 Project Overview

This project aims to enhance public safety by using Artificial Intelligence and CCTV surveillance to detect suspicious or criminal activities in real time.

The system can assist law enforcement agencies in:
- Detecting violent activities
- Identifying suspects
- Monitoring road rage incidents
- Tracking suspicious movement
- Improving investigation efficiency

---

## 🎯 Objectives

- Detect crimes using CCTV footage
- Identify suspects using facial recognition
- Generate automated alerts
- Assist police investigations
- Reduce manual CCTV monitoring

---

## 🛠️ Technologies Used

- Python
- OpenCV
- TensorFlow / PyTorch
- Face Recognition
- Machine Learning
- CCTV Video Processing

---

## 🚀 Features

✅ Real-time CCTV monitoring  
✅ Violence detection  
✅ Suspect face recognition  
✅ Automated alert system  
✅ Smart surveillance assistance
